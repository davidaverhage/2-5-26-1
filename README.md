# React Redux TypeScript Guide – Recompose Examples

This repository contains documentation and example code for using **recompose**
with React and TypeScript. The focus is on showcasing common higher-order
component (HOC) patterns in a way that is easy to adapt in real projects.

## Contents

- [Recompose examples](docs/recompose-examples.md)
- [Example source files](examples/recompose)

> Note: `recompose` is in maintenance mode. These examples are still useful
> for understanding HOC composition patterns and for maintaining legacy code
> bases.
